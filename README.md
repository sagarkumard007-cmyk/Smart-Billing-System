# Smart Billing System

A simple Java console-based billing system built to practice Core Java concepts and basic programming logic.

## About the Project

Smart Billing System allows users to enter customer details, add multiple products, calculate the price based on quantity, and generate a simple bill.

This project was created as a beginner-level Java practice project.

## Features

- Enter customer name
- Add multiple products
- Enter product price
- Enter product quantity
- Calculate product-wise amount
- Calculate total bill
- Generate a simple bill
- Display total number of items

## Technologies Used

- Java
- Scanner
- ArrayList
- Loops
- Conditional Statements
- Basic OOP Concepts

## Java Concepts Practiced

- Variables and Data Types
- Scanner for user input
